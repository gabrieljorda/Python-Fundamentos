# Fundamentos da Linguagem Python

Este repositório é dedicado ao estudo dos **fundamentos da linguagem Python**, reunindo exemplos, exercícios e pequenos projetos desenvolvidos durante aulas e estudos iniciais.

O conteúdo tem foco na construção de uma base sólida em **lógica de programação** e nos principais recursos da linguagem.

---

## 🚀 Conteúdos Abordados

- Sintaxe básica do Python
- Tipos de dados (int, float, string, boolean)
- Variáveis e operadores
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`for`, `while`)
- Funções
- Listas, tuplas, dicionários e conjuntos
- Manipulação de strings
- Entrada e saída de dados
- Introdução à modularização

---

## 🎯 Objetivo

Construir uma base sólida nos **fundamentos do Python**, preparando o caminho para estudos mais avançados, como análise de dados, desenvolvimento web e automação.

---

## 🛠️ Tecnologias Utilizadas

- Python
- Ipynb
